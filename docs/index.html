The Technology Behind Red Grid

Field Link Protocol

Custom BLE + WiFi Direct proximity sync with CRDT-based state management. Delta-encoded updates under 200 bytes each.

Military-Grade Encryption

AES-256-GCM with ECDH P-256 ephemeral key exchange. New session keys every connection. No pre-shared secrets.

MGRS Navigation Engine

10-digit Military Grid Reference System precision. 1-meter accuracy. The same coordinate system used by NATO forces worldwide.

Offline Maps

MBTiles-based offline maps with USGS Topo and OpenTopoMap. Download regions over WiFi, use offline forever.

Zero Footprint Architecture

Red Grid apps collect no data. Your position never touches a server.
